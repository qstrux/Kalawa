## 🚀 Quick Start

### 本地开发

```bash
# 克隆仓库
git clone https://github.com/qstrux/Kalawa.git
cd Kalawa

# 启动本地服务器
./deploy.sh  # 交互式部署菜单

# 或者直接启动开发服务器
npm run dev
# 访问: http://localhost:8080
```

### 部署选项

| 平台 | 命令 | 用途 |
|------|------|------|
| **GitHub Pages** | `./deploy.sh` → 选项 1 | 🌐 生产环境 |
| **Cloudflare Pages** | `./deploy.sh` → 选项 2 | ⚡ 高性能 CDN |  
| **本地服务器** | `./deploy.sh` → 选项 3/4 | 💻 开发测试 |
